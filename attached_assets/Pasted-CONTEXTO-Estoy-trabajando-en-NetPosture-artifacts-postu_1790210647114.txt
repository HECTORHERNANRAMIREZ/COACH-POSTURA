3. Detección de swap por pares, con coordenadas WORLD 3D y usando la última posición ya aceptada de cada punto del par:
   - Calcula el coste sin cruzar: distancia(izq_actual, izq_previo) + distancia(der_actual, der_previo).
   - Calcula el coste cruzado: distancia(izq_actual, der_previo) + distancia(der_actual, izq_previo).
   - Si coste_cruzado < coste_sin_cruzar * SWAP_COST_RATIO (valor inicial 0.6) Y la diferencia absoluta supera SWAP_MIN_GAIN (valor inicial 0.05 metros), marca el frame como "swap candidato" para ese par.
   - Si la distancia entre el punto izquierdo y el derecho previos es menor que SWAP_MIN_SEPARATION (valor inicial 0.08 metros), NO evalúes swap para ese par, porque los puntos están demasiado juntos para distinguirlos.

4. Histéresis para no reaccionar a un solo frame:

Si se confirma, intercambia la asignación de forma persistente para ese par y reasigna también el estado interno relacionado (referencias de hueso, estado de filtros) para no arrastrar historia del lado equivocado.
   - Si mientras es candidato ocurre un frame normal, reinicia el contador de ese par.
5. Mientras un swap es candidato y no está confirmado, entrega al resto del flujo la asignación previa (sin cruzar).

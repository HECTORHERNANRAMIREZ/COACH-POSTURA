---
name: Pull-up session ending
description: The bar-release detector must distinguish a true release from the flexed top position.
---

The pull-up session-ending detector must require evidence of an extended bottom position in addition to wrists dropping below the shoulders/head. Wrist height alone can be misread while the athlete is still holding the bar at the top of a repetition.

**Why:** In the reference recording, the counter froze halfway through the set because flexed elbows placed both wrist landmarks below the shoulders even though the athlete was still on the bar.

**How to apply:** Preserve the bottom-position gate whenever changing pull-up counting or automatic session completion logic; do not broaden the detector based only on 2D wrist/head relations.

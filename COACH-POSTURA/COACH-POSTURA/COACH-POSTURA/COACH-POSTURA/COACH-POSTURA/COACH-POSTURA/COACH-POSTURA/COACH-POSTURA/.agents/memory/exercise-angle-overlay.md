---
name: Panel de articulaciones
description: Regla para que las lecturas visibles representen todas las articulaciones que cada ejercicio realmente evalúa.
---

El panel de grados debe construirse a partir de las articulaciones declaradas por el ejercicio y mostrar sus ángulos individuales; cambiar únicamente el texto del encabezado no completa la solicitud.

**Why:** El usuario espera ver cada extremidad evaluada, incluso cuando una articulación solo se usa como punto auxiliar para calcular otro ángulo. Las lecturas técnicas principales no sustituyen ese resumen.

**How to apply:** Mantén los paneles específicos de fondos y dominadas cuando ya muestran sus articulaciones, evita duplicarlos y usa el panel inferior derecho para los demás ejercicios. En ejercicios bilaterales, etiqueta izquierda y derecha.
